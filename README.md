# Book Lens

Book Lens is a static web app that researches public book data and visualizes how strongly 10 social themes appear in a searched book or full book series.

## Features

- Public-source book and author lookup through Open Library, Wikipedia, and Wikidata
- Full-series aggregation for known series such as Harry Potter, The Lord of the Rings, and Dune
- Korean, English, and Spanish interface labels
- Search autocomplete for curated well-known titles
- Book-specific visual theme and signature image background
